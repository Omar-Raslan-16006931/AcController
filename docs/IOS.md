# AC Controller on iPhone

Two ways to get it on your phone. Option 1 takes 30 seconds; option 2 gives
you a real app icon installed like an App Store app.

Either way the app always shows the latest version of the site: it loads
https://ac-controller-ten.vercel.app, so a normal `git push` (Vercel deploy)
updates the phone too. You never rebuild the iPhone app for UI changes.

---

## Option 1: Add to Home Screen (no computer needed)

1. Open **https://ac-controller-ten.vercel.app** in **Safari** on the iPhone.
2. Tap **Share** (square with arrow) > **Add to Home Screen** > **Add**.
3. Open it from the new icon. It runs full screen, dark status bar, no
   Safari bars, and passkeys / Face ID sign-in work here.

---

## Option 2: Sideload the real app (.ipa) from Windows

### A. Build the .ipa (GitHub does it, free, no Mac)

1. Push this repo to GitHub (the workflow lives in
   `.github/workflows/ios-ipa.yml`).
2. GitHub > your repo > **Actions** > **iOS IPA** > **Run workflow**.
3. Wait about 10 minutes, open the finished run, download
   **AcController-ipa** (a zip) and unzip it: you get `AcController.ipa`.

The workflow rebuilds by itself whenever `frontend/capacitor.config.json`
or the icon script changes.

### B. Install it with Sideloadly (Windows)

1. Install **iTunes** and **iCloud** from apple.com (the non-Microsoft-Store
   versions; Sideloadly needs their drivers).
2. Install **Sideloadly** from sideloadly.io.
3. Plug the iPhone in with a cable, tap **Trust** on the phone.
4. Drag `AcController.ipa` into Sideloadly, type your Apple ID, press **Start**.
   (Use a spare Apple ID if you prefer; it is only used to sign the app.)
5. On the iPhone: **Settings > General > VPN & Device Management** > tap your
   Apple ID > **Trust**.
6. iOS 16+: **Settings > Privacy & Security > Developer Mode** > on, restart.
7. Open **AC Controller**.

**Free Apple ID = the app expires after 7 days.** Re-sign it by running
Sideloadly again (same file), or turn on Sideloadly's auto-refresh, or use
**AltStore** (altstore.io) which refreshes over Wi-Fi automatically. A paid
Apple Developer account (99 USD/year) makes it last a year.

### Dynamic Island (sideloaded app only)

- While the AC is on, the island shows the mode icon and temperature; while
  a timer runs it shows a live countdown (green = turns on, red = turns off).
  Long-press the island for the expanded view. The same shows on the lock
  screen.
- The countdown keeps ticking with the app closed. Other changes (Siri,
  schedules) update the island the next time you open the app; live push
  updates would need a paid Apple developer account.
- If nothing appears: iPhone Settings > AC Controller > Live Activities: on.
- Needs iOS 16.2+ (the app's minimum) and an iPhone with a Dynamic Island
  for the island itself; other iPhones get the lock-screen version.
- Settings > Notifications > Test checks notifications: lock the phone after
  tapping it and the banner arrives 5 seconds later.

### Notes

- Sign in with **email + password** inside the sideloaded app. Passkeys need
  an Apple-verified domain link that sideloaded apps can't have; they keep
  working in Option 1 and in Safari.
- Change the app name, bundle ID or the site it opens in
  `frontend/capacitor.config.json`, then re-run the workflow.
- Icons are generated by `frontend/scripts/make-icons.mjs` on every build
  (no image files to keep in git).
